video-reader — Privacy Policy

A Claude Code plugin that lets Claude "watch" and "hear" videos. Last updated: 2026-05-31.

Summary

video-reader runs entirely on your own machine. It does not collect, transmit, sell, or share any of your data. There is no telemetry, no analytics, and no backend server operated by this plugin.

What the plugin does with your data

  • Video files you point it at are processed locally by ffmpeg (to extract image frames) and whisper.cpp (to transcribe audio). Your video never leaves your computer.
  • Extracted frames and transcripts are written to a local temporary directory on your machine. You can inspect or delete them at any time.
  • Reading the results: the extracted frames and transcript are read by Claude Code in your normal session, exactly like any other local file you ask Claude to read. Their handling is governed by Anthropic's own privacy terms for Claude Code, not by this plugin.

Network access

The plugin itself makes no network requests during normal use. The only outbound network activity is a one-time, user-initiated download of a speech-to-text model (for example ggml-base.en.bin) from Hugging Face, which you run manually during setup as documented in the README. After that, transcription works fully offline.

Third-party tools

This plugin depends on ffmpeg and whisper.cpp, which you install yourself. Those tools are governed by their own licenses and privacy practices. They run locally and do not transmit your data.

Data retention

The plugin stores nothing permanently. Temporary frames and transcripts live in a temp directory until you or your operating system removes them. Uninstalling the plugin removes its code; it leaves no hidden data behind.
